Bank Data Analytics Project | Excel, SQL, Power BI & Tableau

Project Overview

The Bank Data Analytics Project is an end-to-end data analytics project focused on analyzing banking, loan, debit, and credit transaction data using Microsoft Excel, SQL, Power BI, and Tableau.

The project combines data preparation, querying, business analysis, KPI calculations, and data visualization to transform raw banking data into meaningful business insights.

It covers 30 analytical questions across two related analysis tracks: 18 questions focused on banking and loan analysis, and 12 questions focused on debit and credit transaction analysis.

Project Objectives

- Analyze banking and loan-related data to identify business patterns.
- Evaluate debit and credit transactions using relevant KPIs.
- Perform data cleaning, validation, and preparation.
- Analyze loan distribution across states, religions, and product groups.
- Compare credit and debit amounts across banks, branches, states, and customer categories.
- Identify transaction trends, distributions, and potential high-risk or suspicious transactions.
- Build clear and interactive visualizations for business reporting.
- Develop practical skills in data analytics using multiple industry-relevant tools.

4. Tableau

- Connecting and preparing data sources.
- Creating worksheets for individual analytical questions.

- Combining visualizations into an interactive dashboard.

Analytical Workflow

1. Data Collection: Load the banking datasets from Excel and CSV files.
2. Data Preparation: Review columns, data types, missing values, duplicates, and inconsistencies.
3. Data Analysis: Answer the analytical questions using Excel formulas, Pivot Tables, and SQL queries.
4. Data Modeling: Organize the data and establish relationships where required for Power BI.
5. Visualization: Create charts, KPI cards, and worksheets in Power BI and Tableau.
6. Dashboard Development: Combine relevant visualizations into dashboards for easier interpretation.
7. Insights and Reporting: Summarize the findings and communicate the results through reports and presentations.

Key Business Insights

The project is designed to help understand:

- How loans are distributed across states and product groups.
- Differences in banking activity across customer categories.
- Patterns in debit and credit transaction amounts.
- Changes in transaction activity over time.
- Differences in performance across banks and branches.
- Distribution of transaction methods and currencies.
- Potential high-risk and suspicious transaction patterns.

Actual findings and numerical conclusions should be interpreted from the completed analysis and the source data.
